# 📊 Advanced CPU Scheduling Analyzer

## 📌 Description
An advanced desktop application built with Python and Tkinter for visualizing CPU Scheduling algorithms. It features a modern UI with visual Gantt charts and a comprehensive results table.

## 🛠️ Technologies Used
*   Python 3
*   Tkinter & ttk (Advanced GUI Framework)
*   Jupyter Notebook

## ✨ Key Features
*   **Comprehensive Algorithms:** Supports FCFS, SJF (Preemptive & Non-Preemptive), Priority (Preemptive & Non-Preemptive), and Round Robin.
*   **Visual Gantt Chart:** Generates a graphical Gantt chart using Tkinter's Canvas widget to visualize process execution over time.
*   **Detailed Process Table:** Uses `ttk.Treeview` to display a clean table with PID, Arrival, Burst, Priority, Completion, Turnaround, and Waiting times.
*   **Performance Metrics:** Automatically calculates and displays Average Turnaround Time and Average Waiting Time.
*   **Interactive UI:** Easy navigation between the main menu, process input, and results screen.

## 🚀 How to Run
1. Clone this repository.
2. Open the `CPU Scheduling GUI Simulator  (1).ipynb` file in Jupyter Notebook or Google Colab.
3. Run the cells to launch the GUI.
4. Select an algorithm, input the number of processes, fill in the details, and click "Show Results" to see the visual chart and table.
